# Homebrew tap

Homebrew formulae for [JoyoMDEV](https://github.com/JoyoMDEV)'s tools.

```sh
brew install JoyoMDEV/tap/sessions
```

| Formula | Description |
| --- | --- |
| [`sessions`](https://github.com/JoyoMDEV/session-tui) | Terminal UI to browse and resume saved Claude Code sessions |

The formulae are generated and pushed by the release pipelines of the projects they belong to, so don't edit them here.
